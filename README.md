# B2B Marketplace QA Assignment — WholeCart

## Application under test

WholeCart is a business-to-business marketplace for restaurants ordering food, drinks, and supplies from multiple sellers. The application copy and its documentation are provided at [the assignment URL](http://13.200.185.1/c/sathiya-555f4a/).

## Testing objective

Assess release readiness against the Functional Design Document WC-FDD-1.0-434d and approved release changes WC-RN-1.0-434d. This folder contains a documentation-based test plan and test design. It does **not** contain results from executing tests against the application.

## User roles

- **Buyer:** browse and search products; manage cart and checkout; manage orders, refunds, exchanges, invoices, statements, and inquiries.
- **Seller:** manage products and stock; process orders; respond to refund and exchange requests.
- **Operator:** manage marketplace settings and seller approvals; export logistics data.

## Testing scope

Planned coverage includes authentication and role permissions; catalogue and stock; cart and multi-seller checkout; order lifecycle and time/slot rules; invoices and statements; refunds and exchanges; inquiries; seller product/order workflows and CSV import; operator controls and logistics export; partner API; and performance requirements.
