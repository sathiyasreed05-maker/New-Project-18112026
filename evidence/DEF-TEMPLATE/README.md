# Evidence folder template

For each verified defect, create `evidence/DEF-###/` and use descriptive filenames, for example:

- `DEF-001-role-access-denied.png`
- `DEF-002-checkout-total-request.txt`
- `DEF-003-delivery-slot-recording.mp4`

Do not add evidence until it corresponds to an observed and reproducible defect. Remove credentials, API keys, bearer tokens, cookies, personal addresses, GSTIN values, and other sensitive data before storing or committing files.
